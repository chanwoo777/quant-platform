Data sources

The site works without any key. Scores, fundamentals and analytics come from the platform's nightly export (Yahoo Finance, SEC EDGAR, FRED, CoinGecko, Fama-French). Charts load prices in your browser from CNBC and, for coins, Binance; neither needs a key.

Finnhub (optional, free)

With a free Finnhub API key you also get real-time US stock prices in Live, live quotes, analyst recommendation trends and reported financial statements in Financials, and a lookup for US tickers outside the universe.

This is a credential. An API key works like a password for your Finnhub account. Paste only a free Finnhub API key here, never a password or payment details. The site has no server: the key stays in this browser and is sent only to finnhub.io. Unless you tick the box below, it is forgotten when you close this tab. Privacy
